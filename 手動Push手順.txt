========================================
  GitHubへのPush手順（手動実行版）
========================================

【ステップ1: コマンドプロンプトを開く】

方法1: エクスプローラーから
  1. プロジェクトフォルダを開く
     C:\Users\西村康成\WasherInspection
  2. アドレスバーに「cmd」と入力してEnter
     → コマンドプロンプトが開きます

方法2: スタートメニューから
  1. Windowsキーを押す
  2. 「cmd」と入力
  3. 「コマンドプロンプト」をクリック
  4. 開いたウィンドウで以下を実行:
     cd C:\Users\西村康成\WasherInspection

方法3: PowerShellを使う場合
  1. Windowsキーを押す
  2. 「powershell」と入力
  3. 「Windows PowerShell」をクリック
  4. 開いたウィンドウで以下を実行:
     cd C:\Users\西村康成\WasherInspection

========================================

【ステップ2: 現在の状態を確認】

コマンドを入力してEnter:
  git status

表示される内容:
  - "nothing to commit, working tree clean"
    → 変更なし、そのまま進めます
  
  - "Changes not staged for commit"
    → 変更があるファイルがあります
  
  - "Unmerged paths"
    → マージの競合があります（後で解決）

========================================

【ステップ3: マージ状態をクリーンアップ】

マージが失敗している場合、中止します:

  git merge --abort

（エラーが出ても問題ありません）

========================================

【ステップ4: リモートの最新版を取得】

  git fetch origin

これでリモートの情報を取得します（ファイルは変更されません）

========================================

【ステップ5: 現在のブランチを確認】

  git branch

表示例:
  * master
    main

「*」が付いているのが現在のブランチです

========================================

【ステップ6: リモートとの差分を確認】

  git log HEAD..origin/master --oneline

（ブランチがmainの場合は origin/main）

何も表示されない → リモートに新しい変更なし
何か表示される → リモートに新しい変更あり

========================================

【ステップ7: リモートの変更をマージ】

リモートに新しい変更がある場合:

  git pull origin master

（ブランチがmainの場合は git pull origin main）

成功した場合:
  → "Already up to date" または "Merge made by..."
  → そのまま次へ進みます

失敗した場合:
  → "Merge conflict" などのエラー
  → ステップ8で競合を解決

========================================

【ステップ8: 競合を解決（必要な場合のみ）】

競合が発生した場合:

1. 競合ファイルを確認:
   git status

2. 競合ファイルを開く（メモ帳やエディタで）
   例: notepad old\inspection_focus.py

3. ファイル内で以下を探す:
   <<<<<<< HEAD
   （ローカルの変更）
   =======
   （リモートの変更）
   >>>>>>> origin/master

4. どちらを使うか決めて、マーカーを削除:
   <<<<<<< HEAD
   =======
   >>>>>>> origin/master
   これらを全部削除して、残したい内容だけ残す

5. ファイルを保存

6. 解決したファイルを追加:
   git add .

7. マージを完了:
   git commit -m "マージ: 競合を解決"

========================================

【ステップ9: Pushを実行】

  git push origin master

（ブランチがmainの場合は git push origin main）

成功した場合:
  → "To https://github.com/..."
  → "master -> master" などと表示

失敗した場合:
  → "non-fast-forward" エラー
  → ステップ7に戻って再度マージ

========================================

【エラーが出た場合】

エラー: "non-fast-forward"
→ リモートの方が進んでいます
→ ステップ7で git pull を実行してから再度push

エラー: "Authentication failed"
→ GitHubの認証が必要
→ Personal Access Tokenを使用

エラー: "Merge conflict"
→ 競合があります
→ ステップ8で競合を解決

========================================

【よく使うコマンド一覧】

現在の状態確認:
  git status

ブランチ確認:
  git branch

リモート情報取得:
  git fetch origin

マージ:
  git pull origin master

Push:
  git push origin master

マージ中止:
  git merge --abort

変更をリセット:
  git reset --hard HEAD
