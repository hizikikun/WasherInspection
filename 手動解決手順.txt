========================================
  マージエラー手動解決手順
========================================

【問題】
リモートに存在するがローカルに存在しないファイルが原因で
マージが失敗しています

【解決方法1: リモートの状態に合わせる（簡単）】

1. コマンドプロンプトを開く

2. 以下を実行:
   git fetch origin
   git reset --hard origin/master
   git push origin master

これで、リモートの状態に完全に合わせられます
（ローカルの変更は失われます）

========================================

【解決方法2: 手動で解決（時間がかかる）】

1. 問題のあるファイルを確認:
   git status

2. 存在しないファイルのエラーを無視してマージ:
   git pull origin master --allow-unrelated-histories

3. エラーが出た場合、問題のあるファイルを削除:
   （エラーメッセージに表示されているファイル）

4. 再度マージ:
   git pull origin master

5. Push:
   git push origin master

========================================

【推奨される方法】

解決方法1（リモートの状態に合わせる）が最も簡単です。
ローカルの変更が重要でない場合は、この方法を使用してください。

========================================
