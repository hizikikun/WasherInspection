========================================
  手動実行用コマンド集（コピー&ペースト用）
========================================

【ステップ1: 問題のあるファイルをGit管理から除外】
以下のコマンドを1つずつコピー&ペーストしてEnterを押してください。

git rm --cached old/inspection_focus.py

git rm --cached old/inspection_perfect.py

git rm --cached old/inspection_ultra_fixed.py

git rm --cached old/trainer_final.py

git rm --cached scripts/train_4class_sparse_ensemble.py

========================================

【ステップ2: すべての変更をリセット】

git reset --hard HEAD

========================================

【ステップ3: リモートの最新版を取得】

git fetch origin

========================================

【ステップ4: リモートの変更をマージ】

git pull origin master

========================================

【ステップ5: Pushを実行】

git push origin master

========================================

【使い方】
1. コマンドプロンプトを開く
2. このファイルからコマンドを1つずつコピー
3. コマンドプロンプトに貼り付け
4. Enterを押す
5. 次のコマンドに進む

========================================
